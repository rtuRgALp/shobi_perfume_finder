# Shopping-link audit — October 25, 2026

Tested **391 URLs**: **300** containing full or partial designer names, plus the other **91** descriptive product URLs. The remaining catalog URLs use product codes and fall outside this audit's requested scope.

**270 links corrected; 121 existing links verified; no unresolved checks.** Each accepted destination returned HTTP 200 and matched both the existing Shobi product ID and listing code. Identity checks accept only formatting differences around code hyphens. A successful response alone does not prove the correct product.

The 270 old destinations returned 269 HTTP 500 errors and one HTTP 404. All four Abercrombie & Fitch listings were affected: First Instinct, Fierce, Fierce Icon and A&F Beacon.

Old links returning server errors were recovered through Shobi’s product-ID lookup, then verified at the English canonical product URL. Existing links that redirect or contain designer names were retained when the verified canonical destination was unchanged. Percent-encoding alone is not treated as a correction. Raw request results and HTML receipts remain in ignored `data/raw/link-audit/`; the [complete per-link audit](shopping-link-audit.json) records the original URL, HTTP result, verified destination, product ID, heading and check time. These are point-in-time checks, not a guarantee of future retailer availability.
